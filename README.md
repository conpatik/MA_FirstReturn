# MA First Return v1.2 — MT5用

レンジブレイクとSMA25・55のクロス後、短期SMAへの最初の戻りを検知します。設置したチャートの銘柄・時間足で独立動作します。XAUUSDを想定していますが、銘柄名による制限はありません。15分・1時間・4時間足などで利用できます。注文は行いません。

## 導入

1. ZIPを展開します。
2. MT5の「ファイル → データフォルダを開く」から `MQL5/Indicators` を開きます。
3. `MA_FirstReturn_v1.2` フォルダをそのままコピーしてください。EX5・MQ5・MQHを同じフォルダに置きます。
4. ナビゲータの「インディケータ」を右クリックして更新し、`MA_FirstReturn_v1.2` をチャートに追加します。
5. EX5を利用できない場合はMQ5をMetaEditorで開いてF7でコンパイルします。`FirstReturnCore.mqh` と `FirstReturnCSV.mqh` が同じフォルダに必要です。
6. Push通知はMT5「ツール → オプション → 通知」で有効にし、スマホMT5のMetaQuotes IDを登録してテストしてください。

DLL許可や自動売買の許可は不要です。スマホへの通知にはPC側MT5の起動・接続が必要です。

## 売りの判定順序

1. 直前20本のヒゲを含む最高値・最安値の差が、直前確定足ATR14の4倍以内ならレンジとします。ブレイク足をレンジにもATRの参照にも含めません。
2. 確定足の終値がレンジ下限を下回ったら下抜けです。同じ方向のブレイクは、待機中は最初のブレイク時点を維持し、期限を延長しません。固定するのはそのブレイクの判定に使った境界と成立時点であり、価格が後からレンジへ戻ったこと自体では取り消しません。
3. 短期SMAが中期SMAを下抜けた確定足をクロスとします。直前足が同値の場合も、その後下になればクロスです。ブレイクとクロスの順序は不問、間隔は10本以内です。
4. 両方が成立した足より後の確定足で、短期SMAと中期SMAの下向き、および終値が短期SMAよりATRの0.5倍以上下に離れたことを確認します。この離れを確認した足ではサインを出しません。
5. 次の足以降、短期SMAの上下ATR×0.1の帯に価格が入った時点で売り矢印を表示し通知します。陰線確定は待ちません。検知時も短期SMA＜中期SMA、両MA下向きが必要です。
6. 1クロスにつき1回だけです。ブレイクから30本を超えるか、逆クロスになれば、そのセットアップは対象外になります。

買いは上記の上下を逆にした判定です。レンジは値幅だけの簡易定義で、複数回の上下限タッチや高安の波形は検査しません。

## 傾き・ATR・リアルタイム判定

MAと3本前のMAとの差が、ATR×0.05を超えた方向を傾きとします。売りは両方の変化量が `-ATR×0.05` より小さいこと、買いは `+ATR×0.05` より大きいことが必要です。閾値と同値は横ばい扱いです。

ライブのタッチ判定では現在のチャート価格（進行中足のClose）と現在のSMAを使用し、閾値用ATRは直近確定足の値に固定します。クロス・ブレイク・離れの準備条件は確定足だけで更新します。タッチ帯を飛び越したギャップでは検知しません。

## パラメーター

| 名前 | 初期値 | 説明 |
|---|---:|---|
| InpFastPeriod | 25 | 短期SMA、終値 |
| InpSlowPeriod | 55 | 中期SMA、終値。短期より大きく指定 |
| InpATRPeriod | 14 | MT5標準ATRの期間 |
| InpSlopeBars | 3 | MAの傾きを比較する本数 |
| InpSlopeATR | 0.05 | 傾きの最小変化量。下げると横ばいに近いMAも通る |
| InpRangeBars | 20 | ブレイク足より前のレンジ計測本数 |
| InpRangeWidthATR | 4.0 | 許容するレンジ全体の幅。上げると広いレンジも通る |
| InpPairBars | 10 | ブレイクとクロスの最大間隔 |
| InpExpiryBars | 30 | ブレイク後の有効本数。30本目まで有効 |
| InpDepartureATR | 0.5 | 戻る前に必要な終値と短期SMAの距離 |
| InpTouchATR | 0.1 | 短期SMAの上下に設定する接近帯の半幅 |
| InpHistoryBars | 5000 | 過去の判定対象本数の上限目安 |
| InpArrowOffsetATR | 0.3 | 矢印と検知足高安の間隔 |
| InpPopup | true | PCアラート |
| InpPush | true | スマホ通知 |
| InpSound | false | 追加のサウンド再生 |
| InpSoundFile | alert.wav | 追加サウンドのファイル名 |

`InpDepartureATR` は `InpTouchATR` より大きくしてください。黄色系が短期SMA、緑が中期SMA、青い上矢印が買い、赤い下矢印が売りです。

## 過去矢印とライブ矢印の違い

- 初回表示では起動時の進行中足より前の履歴だけをOHLCと確定SMAから推定し、過去分の通知は送りません。起動時の足以降はティックで実際に検知したサインのみを表示します。装着時の進行中足に新しい条件が成立した場合は通知します。
- ライブではティック時点で判定し、出した矢印は同じインジケーターの稼働中は維持します。その後反落・反発しなくても消しません。通知の再送も行いません。通知失敗時はエキスパートログに記録し、自動再送しません。
- MT5再起動、時間足変更、入力変更、付け直しではライブ検知のメモリがリセットされ、過去足から再構築されます。ティック中のSMAの動きはOHLCだけでは復元できないため、矢印が変わる場合があります。停止中・切断中のティックは検知できません。
- 過去足の中で「離れ→戻り」がどちらの順に起きたか不明なため、離れとタッチを同一足では成立させません。リアルタイムでも離れは確定足で確認します。
- 履歴取得範囲・銘柄・時間足によって結果は変わります。スクロールで過去履歴が追加された際も再計算します。

## 検証状況と確認方法

MetaEditorでEX5生成済み、0 errors / 0 warnings。共通MQL判定コアを構文変換して実行する20シナリオのテストが成功しました（買売の対称性、最初の戻りのみ、両MA傾き、期限、クロス順序、ギャップ、同一足での離れと戻りの禁止など）。MT5でのチャート表示・ティック再生・Pushの実送信は未検証です。

まずXAUUSDの15分足・1時間足・4時間足に設置し、SMAクロス、先行レンジ、ブレイク足、離れの確認足、矢印足の順で確認してください。サインが少なければ、まずレンジの最大幅と傾きの閾値を確認します。希望する箇所と実際の矢印を含むスクリーンショットがあると調整できます。
